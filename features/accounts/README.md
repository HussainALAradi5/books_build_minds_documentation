# Accounts and profiles

Registration, login, personal profiles, purchases, activity history, and administrator requests.

Password reset delivers a single-use email code through the server. A mobile number is an optional login identifier; it does not receive SMS. Configure the [external email API](../../integrations/external-apis.md) or development console mode before testing recovery.
